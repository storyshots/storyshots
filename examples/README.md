# Examples Quick Start

To run examples locally:

1. Install root dependencies:

```bash
npm i
```

2. Build packages locally:

```bash
npm run build
```

3. Reinstall to link built bin scripts:

```bash
npm i
```

4. Run an example in UI mode:

```bash
cd ./examples/basic-externals
npm run ui
```

5. Run the same example in CI mode:

```bash
npm run ci
```
